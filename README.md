# Weather Temperature Prediction using Linear Regression

## Project Overview
This project predicts **Temperature (°C)** using historical weather data and **Linear Regression**.
It demonstrates basic data preprocessing, feature engineering, and model evaluation.

---

## Dataset
- File: 'weatherHistory.csv'
- Target Variable: Temperature (C)
- Type: Real-world weather dataset

---

## Machine Learning Model
- Algorithm Used: **Linear Regression**
- Purpose: Predict temperature based on weather conditions

---

## Output
The program produces the following outputs:
- Mean Squared Error (MSE)
- R² Score (model accuracy)
- Actual vs Predicted Temperature graph
- Residual analysis graph

---

## Results
- R² Score achieved: **~0.85 – 0.88**
- Indicates good prediction accuracy for a linear model
---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## How to Run
1. Keep 'weatherHistory.csv' in the same folder
2. Run 'linear_regression_weather.py'
3. Outputs and graphs will be displayed

---

## Conclusion
The Linear Regression model provides a reliable baseline for predicting weather temperature using engineered features.
